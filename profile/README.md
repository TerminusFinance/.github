## ℹ️ About

**Terminus Finance** is a decentralized exchange (AMM) MVP on TON, plus a set of Web3 products — staking contracts and Telegram Mini App games. Open-source smart contracts, backend, frontend and apps.

## 📦 Open-source repositories

### 🔁 Terminus DEX
- **[terminus-dex-core-contracts](https://github.com/TerminusFinance/terminus-dex-core-contracts)** — core AMM smart contracts (FunC)
- **[terminus-dex-pton-contracts](https://github.com/TerminusFinance/terminus-dex-pton-contracts)** — proxy-TON (pTON) contracts
- **[terminus-dex-backend](https://github.com/TerminusFinance/terminus-dex-backend)** — DEX backend / indexer (Python)
- **[terminus-dex-frontend](https://github.com/TerminusFinance/terminus-dex-frontend)** — DEX web app (TypeScript)

### 💎 Staking
- **[ton-staking-contract-v1](https://github.com/TerminusFinance/ton-staking-contract-v1)** · **[jetton-staking-contracts](https://github.com/TerminusFinance/jetton-staking-contracts)** — staking smart contracts

### 🎮 Telegram Mini Apps
- **[telegram-miniapp-tap-game-terminus](https://github.com/TerminusFinance/telegram-miniapp-tap-game-terminus)** — tap-to-earn game · **[fapTapFront](https://github.com/TerminusFinance/fapTapFront)** — tap game frontend · **[wordOfDay](https://github.com/TerminusFinance/wordOfDay)** — phrase/prediction Mini App

### 🧪 StenBit
- **[stenBit](https://github.com/TerminusFinance/stenBit)** · **[stenBitBackEnd](https://github.com/TerminusFinance/stenBitBackEnd)** — see also the [StenBitApp](https://github.com/StenBitApp) org
